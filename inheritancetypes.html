Types of Inheritance

There are basically five types of inheritence.They are

1.SINGLE INHERITANCE
2.MULTIPLE INHERITANCE
3.HIRARCHE INHERITANCE
4.MULTILEVEL INHERITANCE
HYBRID INHERITANCE

1.SINGLE INHERITANCE

If one sub class acquries the properties of another super class is called SINGLE INHERITENCE

2.MULTIPLE INHERITANCE

If one sub class acquries the properties of more than one super class is called MULTIPLE INHERITENCE

3.HIRARCHI INHERITANCE

If more than one sub class acquries the properties of another same super class is called HYRARCHI INHERITENCE

4.MULTILEVEL INHERITANCE

If more than one sub classes are involving in acquring the properties of other classes is called MULTILEVEL INHERITENCE

5.HYBRID INHERITANCE

It is a combination of more than one type of inheritance is called HYBRID INHERITANCE
